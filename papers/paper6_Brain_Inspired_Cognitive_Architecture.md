## 1 引言

### 1.1 问题陈述：推理的五重危机

大语言模型（LLM）在序列预测上取得了工程成功，但作为**推理器**它面临五重结构性危机——不是工程缺陷，而是**架构缺位**（缺少某种数学器官）：

**危机一：幻觉（无验证器官）**. 生成是条件概率转移，没有独立于生成过程的正确性判据；验证只能外挂（RLHF、外部检索），而外挂验证器本身又是另一个会错的 LLM。

**危机二：无顿悟（无全局干涉器官）**. 逐 token 的自回归生成是纯序列机器，没有"场"可供全局共振；推导陷入失效路径时，只会更深地锁定于同一失效路径。

**危机三：无快慢双系统（无经济学器官）**. Kahneman 的 System 1/System 2 分工是算力分配的基本经济学；LLM 对任何难度的问题花费同一单位算力——简单问题过度计算，困难问题计算不足。

**危机四：不可复现（无确定性器官）**. 浮点舍入+采样随机性使同一输入在不同硬件、不同批次上产生不同输出，对科学可复现性、审计与安全认证是结构性障碍；人脑的**决策规律**是稳定的——噪声被动力学收敛掉，而不是被当作采样源。

**危机五：记忆与学习断裂（无内化器官）**. 训练时的梯度更新与推理时的上下文窗口互不相通：上下文里的推理不会固化为权重，权重更新需要灾难性遗忘代价的全量重训；人类技能习得是"逻辑内化为直觉"的连续谱，这一内化机制在 LLM 中完全缺位。

### 2.1 计算基底

素域 $\mathrm{GF}(p)$，$p=65537=2^{16}+1$（费马素数 $F_4$）。全部算术为模 $p$ 整数算术：零浮点、零随机、零舍入。域内关键常数（附录 B.1 机器验证）：

| 常数 | 值 | 恒等式 | 用途 |
| --- | --- | --- | --- |
| $i$（虚单位） | $256$ | $256^2=65536\equiv-1\pmod{65537}$ | 相位门 $S=\mathrm{diag}(1,256)$、Hodge 复结构 |
| $\sqrt2$ | $4080$ | $4080^2=16646400\equiv2\pmod{65537}$ | Hadamard 精确归一化 |
| $1/2$ | $32769$ | $2\times32769=65538\equiv1$ | 手性分解、Kleene 投影 |
| $1/4$ | $32769^2\bmod p=49153$ | $4\times49153=196612\equiv1$ | Kleene 投影 $P_1=\frac14(I+N+N^2+N^3)$ |
| $1/\sqrt2$ | $2040$ | $4080\times2040\equiv1$（因 $4080^2\equiv2$） | Hadamard 系数 |

$p\equiv1\pmod8$ 保证 2 是二次剩余（[Paper3]），$\sqrt2$ 存在；$p\equiv1\pmod4$ 保证 $-1$ 是二次剩余，$i$ 存在——两个常数身份是费马素数的数论馈赠。

### 2.2 留素与留数场

**留素**（residueon，[Paper4]）是三元组 $(z_k,r_k,n_k)\in\mathrm{GF}(p)\times\mathrm{GF}(p)\times\mathbb{Z}^+$：极点位置 $z_k$（场在哪里断裂——粒子性）、留数值 $r_k$（断裂处携带的信息量——波动性）、阶数 $n_k$（断裂深度——拓扑性）。**留数场**是留素的线性叠加：

$$\Psi(z)=\sum_{k=1}^{K}\frac{r_k}{(z-z_k)^{n_k}}.$$

高阶极点（$n_k>1$）对应 [Paper4] 的嵌套分形结构：每个极点自身携带内部留数场。$K$ 个留素的存储为 $O(K)$，求值为 $O(K)$，与底层态空间维度无关（§9.4：这正是留数表作为"代数压缩器"的地位）。

| 算符 | 名称 | 认知语义（本文赋义） |
| --- | --- | --- |
| $\odot$ | GF 域乘 | 突触权重调制 |

| $\Delta$ | Hebbian 雕刻 | 突触可塑性（留数更新 $\Delta r_k=\eta\cdot\mathrm{pre}\cdot\mathrm{post}$） |

### 2.4 三非原则

双路认知架构的三条公理（随机原语被字面定义为恒零——随机性在语言层出局；§4 论证：这三条正是认知系统在噪声环境中稳定运行所需物理约束的人脑版本）：

1. **非不确定性**：Born 选择 = argmax，同输入必同输出（DFL，deterministic fixation of localization）。

3. **非随机**：无采样、无噪声注入；一切分布来自场的确定性干涉。

## 3 留素作为认知原子

### 3.1 三种信息载体的层级

把经典比特、量子比特、留素放在同一张表上：

| 维度 | 经典比特 | 量子比特 | 留素 |
| --- | --- | --- | --- |
| 定义 | $b\in\{0,1\}$ | $\alpha\lvert0\rangle+\beta\lvert1\rangle\in\mathbb{C}^2$ | $(z,r,n)\in\mathrm{GF}(p)\times\mathrm{GF}(p)\times\mathbb{Z}^+$ |
| 参数数 | 1（离散） | 2（连续复数） | 3（离散整数） |
| 位置 | 无 | 无 | $z_k$（有位置） |
| 拓扑 | 无 | 无 | $n_k$（阶数 = 拓扑深度） |
| 演化 | 翻转（可逆） | 幺正（可逆） | Frobenius（可逆）/ Hebbian（有向） |
| 测量 | 直接读 | 坍缩（概率、破坏性） | Born=argmax（确定性、非破坏性） |
| 叠加 | ✗ | ✓ | ✓（留数场 = 留素线性叠加） |
| 粒子性 | ✓ | ✗ | ✓（极点 = 粒子） |
| 波动性 | ✗ | ✓ | ✓（留数 = 波幅） |
| 信息量 | 1 bit | 测量只得 1 bit | $r_k$ 为有限整数，$n_k$ 另计 |

**定理 VI1（载体层级）**. $\text{bit}\subsetneq\text{qubit}\subsetneq\text{residueon}$：

- bit = 留素在 $n_k=0,z_k=0,r_k\in\{0,1\}$ 的退化（可去奇点）；
- qubit = 留素在 $n_k=1$、$z_k$ 固定、$r_k\in\mathbb{C}^2$ 的退化（单极点、连续振幅、无位置无拓扑）；
- 留素比 qubit 多出的两维（位置 $z_k$、拓扑 $n_k$）正是神经科学最需要的两维：神经元有解剖位置，神经回路有拓扑结构。

_证明_：退化映射的直接构造；严格性由参数空间的包含关系给出。∎

关键的不对称：qubit 只有波动性（连续振幅），bit 只有粒子性（离散二值），**留素兼有两者外加拓扑**——唯一能同时编码"什么信息"（$r$）、"在哪里"（$z$）、"多深"（$n$）的离散原子。

### 3.2 量子比特 ≠ 神经元：四矛盾

**命题 VI2**. 量子比特的四项核心特征在神经元上全部不成立：

| 维度 | 量子比特 | 神经元 | 判定 |
| --- | --- | --- | --- |
| 演化 | 幺正（$U^\dagger U=I$，保范数可逆） | 耗散（离子泵耗能，不可逆） | ✗ |
| 测量 | 坍缩（概率性，不可预测） | 阈值放电（确定性，可预测） | ✗ |
| 叠加 | $\alpha\lvert0\rangle+\beta\lvert1\rangle$ 同时存在 | 放电/不放电互斥 | ✗ |
| 纠缠 | 非定域关联（Bell 违反） | 突触连接定域（化学传递 1–100 m/s） | ✗ |

神经元的真实形态是"连续输入（膜电位）、二值输出（脉冲）、阈值确定性"——既非经典比特也非量子比特。**推论：量子比特不是人脑的硬件。**（§15 将给出"但它可能是认知的语法"的结构层救赎。）

### 3.3 神经元 ↔ 留素映射

| 神经元 | 留素 | 依据 |
| --- | --- | --- |
| 解剖位置 $x_j$ | 极点 $z_k$ | 空间编码 |
| 放电率 $f_j(t)$ | 留数 $r_k(t)$ | 强度编码（0–200 Hz ↦ GF 值） |

### 3.4 群体场定理

**定理 VI3（群体场定理）**. 设神经元群体活动为 $A(x,t)=\sum_j f_j(t)\,\delta(x-x_j)$，配核函数 $K(x,x_j)=1/(x-x_j)$ 的场化为

$$A(x,t)=\sum_{k}\frac{r_k(t)}{x-z_k}=\Psi(x,t),$$

则由留数定理 $\oint_\gamma\Psi\,dz=2\pi i\sum_{z_k\in\mathrm{int}(\gamma)}\mathrm{Res}(\Psi,z_k)=2\pi i\sum_k r_k$：**任意包围全群的回路积分只依赖留数和**——全局活动是局部留数的和。波（回路积分，全局）与粒（留数，局部）在神经群体上被同一个定理缝合。_数值验证见附录 B.7。_ ∎

三个直接推论：

1. **脑波 = 留数场**：头皮 EEG 测到的是 $\Psi$ 的低通投影（α 8–13 Hz / β 13–30 Hz / γ 30–100 Hz / δ 0.5–4 Hz / θ 4–8 Hz 频段 = 场的多尺度分量，对应 [Paper1] 多尺度 SSM 的 $K$ 个衰减尺度）。
2. **遗忘 = 留数衰减**：$r_k\to0$ 对应回声衰减 $\lambda^t\to0$（§9.1 的对偶）。
3. **学习 = 留数更新**：$\Delta$ Hebbian $\Delta r_k=\eta\cdot\mathrm{pre}\cdot\mathrm{post}$（GF 版 $(w+\eta\,x)\bmod p$）。

### 3.5 非破坏性测量：回忆不擦除记忆

量子测量是破坏性坍缩——读即毁。留数场的读出（$\downarrow$ Born = argmax）只**选择**振幅最大的极点，场本身原封不动：

$$k^*=\arg\max_k |r_k|^2,\qquad \Psi\ \text{不变}.$$

即 NDM（non-destructive measurement）。认知对应：**回忆不消耗记忆**——同一记忆可反复思考而不磨损；三非的"非耗散"在认知语义下即此条。工程对应：ΨDB 读事务永不修改极点表（写走 WAL/快照通道——双代快照与操作级 WAL 的断电安全层），库即程序、读即求值。

### 8.1 修正一：分离用 grade involution

**错误版本**：$P_\pm=\frac12(1\pm I_5)$ 是左右投影。**勘误**：$I_5^2=-1$（5 维签名 (4,1)：$I_5^2=(-1)^{5\cdot4/2}\,(+1)^4(-1)=-1$）导致 $P_+P_-=\tfrac14(1-I_5^2)=\tfrac12\neq0$、$P_+^2=\tfrac12I_5\neq P_+$——交叉项不消除、幂等性不成立，$P_\pm$ 根本不是投影（附录 B.6 验证）。

**正确版本**：分离算子是 **grade involution**：$\hat A(M)=\sum_k(-1)^k M_k$（每个 $k$-grade 分量乘 $(-1)^k$），$\hat A^2=+\mathrm{id}$。

$$M_+=\tfrac12(M+\hat AM)\in\mathrm{Cl}^+(\text{偶部}),\quad M_-=\tfrac12(M-\hat AM)\in\mathrm{Cl}^-(\text{奇部}),\quad M_\pm^2=M_\pm,\ M_+M_-=0$$

病因学：标准化特征使零初始化 logits≈0、softmax 梯度消失（早期靠原始幅值特征 ‖h‖~10⁷ 掩盖）；点积原型被长尾类少样本范数爆炸垄断（单样本类原型=样本本身，范数 √F）；余弦归一+温度缩放是最小修复。**教训入册：高维类均值判别式必须余弦化。**

**中文实测**（GPT-NeoX 字节级 BPE）：分词效率 **1.41 token/字**（英文 1.31 token/词；478/512 中文 token 为整字 merge）；引擎头命中中文 36.24%（n=6,927）vs ASCII 36.53%（n=6,493）——**无显著差距**。字节级链路对中文开箱即用；代价仅在生成端（逐片段解码错字率）与 ~1.4× token 税。词表中文化手术（追加行+byte-fallback embedding 均值初始化，Lovelace 教义一致）。

**克利福德升级探针**（1M 语料，回应"Cl(4,1) 升级读出"主张的先行检验）：非对角二次项 h_i·h_j（i≠j，随机 768 对，seed 42）是几何积的最小可测化身。判决：P 臂 42.40%（≈线性 42.26%，+0.1 pp）；CP 45.24%（=CA，P 被 C 冗余）；**CPA（完整二次族）46.47%，+1.25 pp**——增量真实但小，上界不在特征类（blade 特征期望收益同量级）。**正确落点不是读出精度，而是门残差适配器（M₂+ΔR Hebbian，控制生态位）、几何域 rotor（渲染/机器人）与双域 GF(65537)×GF(131071) 交叉审计**；优先级：①适配器 ②双域审计 ③手性双路（grade involution 免费；P±=(1±I₅)/2 非投影，分离用主对合，翻译用 Hodge 星=±256 复结构）④Born 多基读出（低优先）⑤MPS/纠缠延期（留素表 K 极点稀疏即已有压缩；容量界见定理 VI9）。

**门残差适配器 MVP**（全 GF(65537) 确定性）：8 人格各受确定畸变（20 通道乘法掩码），共享任务=GF-线性探针 16 类。共享无适配 8.11%（畸变摧毁）→ **门残差适配器（块对角 2×2 门 ×10，每人仅 40 整数 ΔR，GF 精确反演求解）8/8 人格 100.00% 恢复**，参数为全量独立读出（640 整数/人）的 **1/16**——万级 NPC=共享门基表+个体 ΔR 得到机制验证。GF 域方法论三律：**①嵌入必须满秩（Vandermonde 幂次，共秩特征必死）②GF 域 ridge 无意义（无拓扑⇒λ 扰动=本质随机解），一律 λ=0 精确解+互异行选取保证非奇异 ③one-hot 回求学不出 argmax，读出须回归分数本身（score-matching）**——fp64 习惯不迁移 GF 的典型实证。

**适配器 T2：非线性边界与双域审计**：畸变升级为块内二次交叉耦合后，**线性人格 lin/quad/full 全 100%（复现 MVP）；二次人格全线性类臂全灭（lin 3–10%，二次提升门 4–11%，全量独立读出也仅 6.2%=随机）**——边界属于线性解码器架构整体，非适配器独有缺陷；逆转二次畸变需真非线性读出。**双域审计（GF(65537)×GF(131071)）：关系级校验 R·D≡I 各域自洽，损坏检测率 100%，误报 0%**。教训：嵌入幂次须 lift-aware（幂次 3i+1，平方项幂次 ≡2 mod 3 不碰撞）；P1 的逆不是 P2 的逆（双域各存自家逆元）。

**适配器 T3：非线性逆转分级判决**：①**单向耦合（β=0）提升适配器 [x′, x′²] 40 维精确解=4/4 人格 100.00%**——代数预判（x_a=(u_a′−α·x_b²)/d_a 恰在 span 内）被证实，适配器从纯线性扩至单向二次，成本仍 40 整数/人；②双向耦合 lift 仅 40% 部分恢复（四次污染项），**GF 定点迭代不收敛（fp0–fp3 全随机：有限域无收缩几何，又一 fp64 直觉阵亡）**——双向精确逆转需四次方程机器（GF sqrt/Tonelli-Shanks 已有）。能力阶梯：线性 100% → 单向二次 100% → 双向二次 40%（lift）。

**蒸馏生成头：突破判决**（RTX 2060 GPU）：教师热启动+储备池残差——logits = lm_head@φ（冻结=引擎头本体，起点=教师）+ ΔW@ψ（可训 CA 骨架残差），CE 硬标签校准，全词表 50280。**3.7M 语料 held-out：55.94% > 引擎锚 52.72%（+3.2pp）——首次有学习读出在干净异质语料上反超引擎头**，softmax 校准+全词表从构造上消解生成两大障碍（不校准/闭词表）；训练 250K 位子采样 × 3 epochs ≈ 3.5 min/epoch。『后验读出不可逾越联合预训练解码器』由此改写：**差距不是墙，是缺一块热启动残差头**。剩余：贪心生成分辨率验证与全量扩展。

**生成判决：储备池长文本生成式推理实体现**：蒸馏头贪心生成三 prompt 全过——「def gate_step(x):」生成**结构完整语义正确的 Python docstring（含 Args 节）**，优于引擎头；「Once upon a time」与引擎头逐词一致（平价）；「The capital of France is」流畅英语（distinct 26 vs 25）。**白盒 GF 精确可训的储备池解码器生成真实语言——本系列从『读出研究』升格为『生成引擎』。**

认知环（本文）不与浮点大模型比刷分——它的赛道是**可复现、可审计、可物化**。

#### 17.3.10 蒸馏生成头：技术细节与判决修正

（生成结果见 17.3.9 末两段；本节补细节与判决修正。）

**配方**：$\text{logits}=\mathrm{lm\_head}\cdot\varphi+\Delta W\cdot\psi$——$\varphi$ 为引擎 rmsnorm 复现（构造保证起点=引擎头本体）；$\psi$ 为骨架跨组积（L16 Morse 骨架 58 通道 → 56 归因组，$\psi=\mathrm{CA}(h)$）；$\Delta W\ (1540\times50280)$ **只学**"教师错而储备池特征知道的修正"——残差头而非替换头。语料升级至 **10M token**（文档级切分，held-out 563,406 位），250K 位 × 3 epochs ≈ 281 s。

**ΔW Q15 量化门（ψ 原生前提）**：$\max|\Delta W|=0.0785$；定标扫描 $s=12$ 起与 fp32 一致率 **99.96%**、acc 零损失（$s=14$ 起 100%）——学生头全程 Q15 整数化可行，符合三非。

**判决修正三条**：①17.3.4"特征与训练目标正交"结论收窄——TCAR 轨迹特征确实不适合生成，但**骨架组归因特征**（因果检验幸存者）既能读也能写：乱码的根因是特征，不是"学习读出生成"这个范式；②**差距不是墙，是缺一块热启动残差头**——学习读出对联合预训练解码器的 7.5 pp 上界被残差架构改写为 +3.2 pp 反超；③生态位修正：学习读出从"窄域分类/控制/归因"扩展为"窄域 + 蒸馏生成"。

**实现注记与遗留**：$\Delta W$ 转置方向 $\psi@\Delta W$ 连犯三次；GF 域 $\lambda=0$ 精确解；$\psi$=CA(h) 勿与嵌入 $x$ 混通道。遗留：40 token × 3 prompt 为定性判决，规模化基准与人工评测为下一步；中文生成依赖词表中文化手术（前置项）。扩展方向（Phase 1：L16 扩至 L16+L17+L20、训练位 250K→2M、ΔW 修正 top-100→top-5000，保留热启动与 λ=0 闭式解）。

#### 17.3.11 中文蒸馏头：基线上界、v1 迭代、技术域探针与 α 扫描终判

17.3.10 英文蒸馏头在干净语料上反超引擎头 +3.2 pp 且三 prompt 流畅生成；本节记录移植中文后的判决链——四轮实验钉死"**next-token 命中率 ≠ 多 token 生成质量**"，终判：生成时 $\Delta W$ 归零。实验均在 Mamba-130M-HF + RTX 2060 GPU，配方与英文版同构（$\varphi$=原装头冻结、$\psi$=L16 骨架 56 组跨组积、SGD lr=0.1 × 3ep × 250K 位、batch 1024）。

**（A）BPE 基线上界**。词表 50277 中仅 313 个中文 token（0.62% 覆盖），token 税 1.7–1.9 token/字；命中率中文 31.36% vs ASCII 44.54%（−13.2 pp）；8/8 对话 prompt 贪心逐字重复。词表中文化是前置手术，但 130M 的 BPE 词表不可换（$\varphi$ 锚定），蒸馏头只能做增量。

**（B）v1 蒸馏头三轮迭代**——v1a 双重 norm bug（teacher 锚 7.5%）；v1b norm 后态算 $\psi$（teacher 锚 38.5%→distill 39.0%，+0.48 pp，复读 10/10）；v1c norm 前态 + zrep(64)（38.5%→39.0%，**+0.50 pp**，复读 **0/10**）。

钉扎级发现：①`hidden_states[-1]` 已过 final norm（直接出 logits 与 native argmax 一致率 99.27%，重复 norm 后 8.6%——argmax 口径；命中率随之 38.5%→7.5%），norm 前态须手工循环 24 层拿；②$\psi$ 必须用 norm 前残差流（英文版从 Q15 原始态算的同源构型）；③zrep $\sigma$ 惩罚窗口须覆盖循环周期——recent=8 只治 token 级死循环，recent=64 后短语级循环（周期 20–40 token）归零。验收门：gate_b **PASS**（复读 0/10），gate_a **FAIL**（$\Delta$+0.50 pp $\ll$ 英文 +3.2 pp）；主嫌初判域错配（语料 100% 技术文档 vs prompt NPC 对话）。

**（C）技术域探针——反证域错配**：若域错配是主嫌，训练同域 prompt 上生成应有效（4 技术 prompt × 双头 × 500 token）。崩点：#0 矩阵乘法 distill **13**/500 vs teacher 500/500（−487）；#1 代码功能 **27**/500 vs 500/500（−473）；#2 改进方案 **10**/500 vs 34/500（−24）；#3 词法分析 **238**/500 vs 24/500（+214）。

distill 0/4 全程通过（中位 27）vs teacher 2/4（中位 500）——**反证**：同域仍劣，域错配非主嫌。真因：$\Delta W@\psi$ 在 OOD 拼差流上把 logits 推向训练高频模板（"矩阵"/"onCreate"/"构建逻辑"），坍缩复读；zrep 1.2$\sigma$ 压不住 $\Delta W$ 注入的超高 logit（崩点 10–27 $\ll$ recent=64）。

**（D）α 扫描终判——无最优点**：蒸馏头 = 原装头 + $\alpha\cdot\Delta W@\psi$，扫 $\alpha\in\{0, 0.3, 0.5, 0.7, 1.0\}$（崩点 #0/#1/#2/#3、全程、中位）。技术发现：`model.forward(use_cache=True, output_hidden_states=True)` 返回 25 元 hidden_states，`hs[-2]`=norm **前**态（与手工循环 max\_diff=0.0000）、`hs[-1]`=norm 后态——增量 cache 每步 O(1) 取之算 $\psi$，**约 24× 加速**（500 token：非缓存约 500 s vs 增量 21 s）。结果：$\alpha$=0.0（1 / 500 / 61 / 56，**1/4**，中位 61）、$\alpha$=0.3（1 / 500 / 75 / 27，**1/4**，中位 75）、$\alpha$=0.5（1 / 39 / 49 / 36，0/4，中位 39）、$\alpha$=0.7（0 / 49 / 67 / 99，0/4，中位 67）、$\alpha$=1.0（0 / 27 / 3 / **238**，0/4，中位 27）。

**不存在使 $\Delta W$ 一致改善生成的 $\alpha>0$ 最优点**：$\alpha$=0.0 与 0.3 并列最优（各 1/4），$\alpha$=0.3 在 #3 崩@27（vs $\alpha$=0 的 56）；$\alpha\geq 0.5$ 明显劣化（#1 从 500→39：$\Delta W$ 把 Java 代码生成引向"空间类型"模板后复读），毒化阈值 $\alpha\approx 0.3$–0.5；#3 唯一例外（$\alpha$=1.0 崩@238 > $\alpha$=0 的 56），个例不改趋势；#0 崩@1 是 12-gram 判据对 Java 代码块空白重复的误报。

**（E）终判与生态位修正**：A 钉死 BPE 上界（31.36%）→ B v1 gate_b PASS/gate_a FAIL（+0.5 pp）初判域错配 → C 探针反证（distill 0/4 vs teacher 2/4）→ D 无最优点（$\alpha$=0 最优）→ **终判：生成时 $\Delta W$ 归零**。核心矛盾：$\Delta W$ 提升 teacher-forced 命中率 +0.5 pp，但自回归生成时每步 $\Delta W@\psi$ 把 logits 微推向训练高频模式，多步累积后坍缩复读；更底层约束是**中文 next-token 熵高**（teacher 锚 38.5% 对英文 52.7%）。**增量蒸馏已完成（17.3.10 英文 +3.2 pp 成立），但中文生成端增量为零——next-token 准确率 ≠ 生成质量。** 生态位修正：中文生成 = 引擎头 + zrep(recent=64)，蒸馏头在中文生成端是负效果。


#### 17.3.12 中文行通道与训练场会师：双头架构的工程实证与“行追加”范式

（全部实验位级/账本可溯。）

**（A）UTF-32 读出行：首个真汉字。** §17.3.7 末注的 UTF-32 原生编码提案获首次工程验证：以闭式 ridge（训练=反演，§10.6）在冻结引擎终态隐态上拟合 270 字读出头（测试 89.86%，多数类基线 1.87%，48× 信号；单字 BPE 子集探针 97.1%），按 Q15 定标写表（`round(W×32768)`）；纯 PsiLang 链路（q15 prefill→终态归一→点积→argmax→码点，零第三方零浮点）吐出首个生成汉字**「你」**（U+4F60，zh-logit 47001）。两条纪律入册：①浮点→定点转换必须先定标后取整，裸 `round` 曾把全表打成零（|W|<0.5 的判别信息全在小数部）——转换后非零计数断言成为固定守卫；②ψ 表族必须成套写、互断言（曾发现 183 字过期 chars 表与 270 字 head 表并存，v2 解码成功属 argmax 落在重叠区的运气）。

**（B）输入侧行合法化。** 只训读出行时输入仍走 BPE 字节碎片——汉字无法以一等 token 进场（17.3.11(A) 上界）。解法与冻结铁律相容：新增 K×768 **输入行** E 与读出行 W 联训，梯度穿过冻结骨干回传、场参数零改动——加行不打补丁，与 §17.3.9“微调场违冻结铁律”不冲突。穿冻结引擎合法化验证 69.36%（前位状态配对口径）；输入侧行把 17.3.11(C) 的 OOD 差流问题从根上移除——输入不离场，而是行族成员。

### 17.6 认知遗忘手术：极点页表实测

遗忘律（§12.4）说记忆按闲置降解，本节回答更进一步的问题：**遗忘是否可寻址**——能否只删除一条记忆而邻位记忆无损？载体取 Mamba3-MIMO 架构的最小实现（26M 参数，2 层 × 8 头 × 双秩 × 64 状态；每头一个时标参数 $\mathrm{dt\_bias}$，状态转移含衰减因子 $\exp(A\cdot\mathrm{DT})$），在两条句子上过拟合收敛后做极点手术。

**结构更正（自我纠错入册）**。若把 `mimo_z` 的中间轴读作实部/虚部，会得出"|z|≈√2、arg=π/4=T 门相位、极点自发落在 GF(65537) 代数分点"的解读——已被 mamba_ssm 实现**证伪**：`mimo_z/x/o` 形状 $[8,2,64]$ 是**（头，MIMO 秩，头维）的秩混合矩阵**（初始化值 1.0/0.5/0.5，训练后偏差 <0.5%），√2 是把秩轴当复轴算模长的伪象。真极点在衰减通路：每头时标 $\mathrm{DT}=\mathrm{softplus}(\mathrm{dd\_dt}+\mathrm{dt\_bias})$ 与衰减 $A=-\mathrm{softplus}(\mathrm{dd\_A})$（钳位 $\le -10^{-4}$），状态转移 $\exp(A\cdot\mathrm{DT})$。教训：**权重形状的语义必须对实现钉扎，不能按字段名猜测**。

**顺序形式参考实现**。按内核数学逐项重写的纯 PyTorch 实现无任何 CUDA 依赖：梯形离散化 $\mathrm{trap\_scale}_t=\mathrm{DT}_t\sigma(\mathrm{trap}_t)+\mathrm{DT}_{t+1}\sigma(-\mathrm{trap}_{t+1})$、时间相关旋转角 $\theta=\mathrm{mod}_{2\pi}(\text{chunk 累积}\ \tanh(\mathrm{angle})\cdot\pi\cdot\mathrm{DT})$、旋转只转前 16 维按 $n\leftrightarrow n+32$ 配对、同 token 对角项用**未旋转** qk、输出经 $\phi\cdot\mathrm{SiLU}(z\cdot\zeta)$ 秩门控后求和。该实现在 CPU 上**逐字复现官方 TileLang 内核的全部演示输出**（3/3，含两条训练句的完整续写）——语义级的"过海关"验证（§17.5），一个可携带的 Mamba3 语义基准。

**五项实测**：

1. **乘积静默等效**。头输出 ∝ 输入耦合 × 输出混合 × $\mathrm{SiLU}(z\cdot\zeta)$ 为乘积结构，三路任一置零都使整头静默。7 通路 × 16 头实例 = 112 个单点消融中 102 个生成逐字不变——记忆不住在任何单头里。
2. **分布式容错**。同时静默 10/16 头实例（62.5%）记忆句仍逐字完好；12/16 起截断；16/16 崩溃。逐步 argmax 裕度地板 9.0 nat：单头扰动被裕度吞没。鲁棒性 = 分布式冗余 × 记忆化裕度。
3. **全局时标重标定不变性**。16 个时标同时归零（各头时标统一重标定）生成逐字不变，单独归零 1 个即截断——记忆依赖头间时标的**相对比值**（齿轮比）：整体缩放仍是那台钟，单独换一个齿轮就停摆。
4. **单侧死区**。单头时标加负偏移（放慢遗忘）直到底部无行为改变；加正偏移（加速遗忘）阈值 +3.5～+5，越过即截断。**记忆可以无限变长，不能变短**——长程上下文混合是承重结构。
5. **极点页表（选择性遗忘）**。两条记忆的冗余头集合不同（记忆 1 在头 (0,7) 冗余、记忆 2 在头 (0,2) 冗余），单极点时标归零实现**双向定向截断**：归零 (0,2) → 记忆 1 截断为前半句而记忆 2 逐字完好；归零 (0,7) → 记忆 2 截断而记忆 1 完好；归零 (1,0)/(1,4)/(1,5) → 记忆 1 分别死在倒数第 3/2/1 个词——**不同极点承载记忆链的不同下游区段，时标参数就是可寻址的记忆页表**，遗忘律的"闲置降解"之外存在"定向降解"，地址空间 16 个条目。

| # | 手术 | 门语义 | 实测 |
| --- | --- | --- | --- |
| 1 | 置零输入耦合 / 输出混合 / 门控任一路 | **静默门**（乘积结构三路等效） | 112 个单点消融 102 个生成逐字不变——记忆不住单头 |
| 2 | 同时静默 k/16 头实例 | **冗余半径** | $k\le 10$ 逐字完好，$k=12$ 起截断，$k=16$ 崩溃；argmax 裕度地板 9.0 nat |

### 17.7 黑盒的完美分解与两把尺实测：从巨量相消到球账仪表盘

剖检发现单通道读出幅值（±10⁹）与相消后净声（~10⁵）差四个数量级，问题随之而来：**这个叠加能否被完美分解**——非掩码、非路由、非基截断（§17.3 三路全灭），而是把净声无损拆回分量并逐位装回。本节在 Mamba3 最小实现（§17.6 载体）上闭合此问题，使 §13 两把尺（PCD/RRC）在球账级工程实现；全部实验在纯 PyTorch 顺序形式参考实现（float64，无厂商内核）。

**分解的合法性先于技术**。三路历史失败检验的都是"减少分量后表示是否仍可用"——压缩问题；正交基满秩（谱平）不构成反例：**一个对象可以在一切正交基下稠密，却在极点基下只有 K 个分量**——合成域演示（GF(65537)，K=12）：分量幅度 ±63000 叠加成 ±472 微弱通道（**134× 相消**），Hankel 逐阶精确递推+特征多项式求根+Vandermonde 解留数给出**极点 12/12 命中、留数逐位精确、64 步回程票逐位全同**；同一实例 float64 求解留数误差 44%（Vandermonde 条件数 2.9×10³⁴）——**相消是浮点的死刑、精确算术的无关项**。K 取全部极点时分解不再是拟合而是恒等式："拟合"与"表示"的分界线就是回程票。

**真模型三账**。每层每头块输出精确展开为命名路径（来源位置 × 写秩 → 读秩的记忆痕迹、同位对角、跳跃旁路），经 out_proj 投影到 margin 方向：**A. 回程票** max|Σ路径−块输出| = 8.3×10⁻¹⁷（机器精度）；**B. 配方** margin = Σ⟨v, 路径⟩ 差 = 0.00e+00——黑盒决策被逐位翻译成"球清单+配方"（" even"的逐球账单：球(1)←'amba' +2.06、球(1)←'M' +1.26、对角/旁路次之）；**C. 框架同源**——框架内模拟 §17.6 时标归零手术，三种手术截断逐字复现 f32 真手术账。结构副产物：**MIMO 状态跨秩共享——每头是 2×2 读写交叉开关**，语义组件天然是立体路径而非平面通道。

**遗忘的因果瞬间**。失效步账单：**遗忘不是记忆被擦除，是失调分量的账单幅值淹没了正确答案的贡献**——手术球自身账单 +0.15→+1.83，其余七球集体翻负（−0.3~−3.2；无残差架构下手术球输出毒化层输入，读出全部移位），正确答案跌至第 2 名、只落后 EOS 0.11 nat。

**平衡恢复曲线**。将失调分量逐级衰减（输出混合 ×α 扫描），度量**平衡放大率 $A=\sum_i|b_i|/|\sum_i b_i|**（$b_i$ 为逐球账单）：全腐坏时 **A=304.9、净账塌至 +0.01**（八球账目相互抵消，净账为巧合残余）；α 单调下降时 A 单调回归——5.57→2.97→1.85→1.50→1.22→1.10→**1.00**——从部分恢复到逐字基线。健康态 **A=1.00 精确**：球与球全对齐，巨量相消发生在球内路径级与通道级（剖检的 10⁹/10⁵），不在球间——**相消是分层的**。

**命题 VI28（相消分层律）**. 巨量通道相消是**分层的**：相消在球内路径级与通道级（单通道读出 ±10⁹ vs 净声 ~10⁵），球间账单全对齐（健康 A=1.00 精确）；语义住在**相消的余数**里。四现象同源：①float64 在 134× 相消下留数误差 44% 而 GF 逐位精确——浮点死刑即相消死刑；②GF 精确算术是构成性要求；③记忆轴剪枝“学习满分/推理崩塌”双面账（学习读出利用余数残差结构，argmax 消费余数本身）；④精度悬崖（§17.3(B2)）——扰动破坏的是余数而非幅度。∎（机器账 B.23；方向谱 241 向实测。）

**外在/内蕴判决与三条方法论定律**。对同一死亡前缀做 241 个 token 方向的 A 谱扫描：①健康介质的 A≈1 **只在被问的方向上成立**（随机方向 A 中位 1.7~1.9、极大值 700+ 而无害）——介质是干涉器件，**A=1 是对问题的动态应答**；②手术不碎流形全局（随机方向中位 A 反降），只杀死对当前问题的对齐响应——**划痕在内蕴侧（动力学），症状在外在侧（方向选择性），诊断必须问题条件化**；③手术态出现**独唱陷阱**：单球支配使多数方向"平凡对齐"（A→1 而内容已死）——**A 必须与声部数（participation ratio）共读**。另：手术态状态范数偏离基线 5~9× 却遍历所有步——**测地距离不是语义破损探针**，距离规范依赖而相干规范不变（§7.1 第二独立论据）。刚柔边界由部分分式唯一性给出：**删极点=更换函数类**（极点集唯一标识有理函数——离散、拓扑级、不可连续恢复），**时标/幅度调节=连续曲率形变**（单调可恢复）。


## 18 环境交互学习：多体认知场与自适应闭环

本部分把 §10.7 波场定位展开为完整闭环：**环境是外部波场介质**，交互即激励-响应-观测；单认知体四拍闭环（观察→推理→行动→学习）正是 §12.1 统一场方程的离散化——$J(t)$ 是感官输入，Born 选择是读出，Hebbian 雕刻是极点谱更新；写入地址与可逆性由 §17.6 极点页表保障，健康监测走 §13.6 两把尺（$A$、PCD、RRC）。多体下，§13.5 Kuramoto 同步从病理判据升格为社会认知涌现机制。

### 18.1 单认知体 = 单留数场实例

一个认知体的最小数学单元是留数场 $\Psi_i(z)=\sum_k\frac{r_k}{(z-z_k)^{n_k}}$，极点集 $\{z_k,r_k,n_k\}$ 编码全部记忆与技能，状态空间为 GF(65537)^N（N 为极点维度）。四步闭环（同输入永远同输出，DFL）：**观察**——$J(t)$ 作新极点注入，$\Psi_{\text{obs}}(z)=\Psi(z)+\frac{J(t)}{z-z_{\text{sensor}}}$；**推理**——查询点 $z_q$ 求场值 $\Psi(z_q)=\sum_k\frac{r_k}{(z_q-z_k)^{n_k}}\in\text{GF}(65537)$；**行动**——Born 选择 $a^*=\arg\max_{a\in\mathcal{A}}\big|\Psi(z_a)\big|$（候选集 $\mathcal{A}=\{a_1,\dots,a_m\}$，$a_i$ 对应场值 $\Psi(z_{a_i})$）；**学习**——环境反馈 $r_{\text{env}}\in\text{GF}(65537)$ 更新极点留数：$r_k\leftarrow r_k\boxplus\Delta r_k,\ \Delta r_k=G\cdot r_{\text{env}}\cdot\big(z_{\text{env}}-z_k\big)^{-n_k}$（$G$ 为可塑性增益，域内整数；$\boxplus$ 为 GF 加法）。

### 18.2 环境反馈作为外部极点

环境不是外部黑盒，而是与之叠加的留数场：$\Psi_{\text{total}}=\Psi_{\text{internal}}+\Psi_{\text{env}}$。观测序列经矩量窗分析，由 Berlekamp-Massey 算法提取极小线性递推系数 C[L] 作为新极点写入留数表；Bragg 验证（尾段逐点镜像复算）确保写入的律结构与环境真实动力学一致——任一不符即拒结晶。

**BM 极点提取**：观测序列 $\{o_t\}_{t=1}^{L}$（$o_t\in\text{GF}(65537)$）满足递推 $o_{t}=\sum_{i=1}^{d}c_i\cdot o_{t-i}\pmod{65537},\quad t>d$，特征多项式 $C(x)=x^d-\sum_{i=1}^{d}c_i x^{d-i}$ 的根 $\{\zeta_j\}$ 给出环境极点位置，留数由部分分式分解确定：$\Psi_{\text{env}}(z)=\sum_{j=1}^{d}\frac{\rho_j}{z-\zeta_j},\ \rho_j=\frac{\zeta_j^{L}}{C'(\zeta_j)}\prod_{t=1}^{L}(o_t-\zeta_j)$。Bragg 验证：用 $\{\zeta_j,\rho_j\}$ 重算前 $L/2$ 项逐点比对，差异度 $D(Q)<0.01$ 方可结晶写入；超限表明非线性度超出线性近似，需提高阶数 $d$ 或分段提取。

### 18.3 多体场干涉与 Kuramoto 同步

N 个认知体构成多体留数场系统，第 i 体相位服从 Kuramoto 方程

$$\frac{d\theta_i}{dt}=\omega_i+\frac{K}{N}\sum_j\sin(\theta_j-\theta_i),$$

$\omega_i$ 为固有频率，K 为耦合强度，同步阈值 $K>K_c=2/(\pi g(0))$ 给出集体相变临界。认知意义：**健康临界区** $0.3<R<0.7$——个体保持独立动力学、全局信息整合最大化（正常社会认知）；**过度同步** $R\to1$——相位完全锁定、独立认知归零（群体思维或癫痫样病理）；**完全失同步** $R\to0$——无信息交流（昏迷或社会解体）。社会认知涌现 = 集体 PCD 相变：足够多认知体进入相位相干态，序参量连续出现（Landau 二级相变），集体认知形态（规范、语言、文化）作为涌现极点谱稳定存在。

多体通信不搬运数据：**偏转同步**三量协议（$\Psi_{\text{global}}$、$\Psi_{\text{local}}$、$\delta=\Psi_{\text{local}}-\Psi_{\text{global}}$）是混沌同步的波场形态——客户端只上传微观偏转参数，服务器经 PCD 一致性校验后广播粗粒化拓扑摘要，各端因底层方程一致自动演化出相同效果；跨体传输最小单元是拓扑不变量（Betti 数+相位边界）：干涉意图，而非搬运状态。

### 18.4 训练场：可控环境下的学习闭环验证

训练场是认知架构从理论到工程的关键验证环节，核心设计原则：**可控压力 → 可观测学习 → 可验证收敛**。

#### 18.4.1 机器人路径规划

机器人训练场验证物理控制域适用性（状态=机器人/目标坐标与障碍物分布，行动=离散移动指令）：**路径 = 代数曲线上的极点追踪**（每步由 Born 选择从当前场分布确定）；**奖励 = 场强反比**（目标距离平方倒数 $r=1/d^2$，越近越强）；**碰撞检测 = 极点共享**（机器人极点与障碍物极点重合即碰撞，GCD 检验）。

#### 18.4.2 训练闭环

完整训练循环四阶段：

1. **Episode 执行**：执行策略，记录轨迹（状态-行动序列）；
2. **DB3 存储**：轨迹作为极点序列写入三维数据库（每路径点=一个留素极点）；
3. **Hebbian 学习**：环境场按 $env\leftarrow env+\eta\cdot trajectory$ 更新，学习率 $\eta$ 为 GF(65537) 域内整数（典型值 4 或 5）；
4. **动画回放**：多帧规则流回放，供离线复盘与策略优化。

学习不是梯度下降，而是留数场的确定性叠加——环境场与轨迹场的几何和构成新环境场，无需反向传播。数学描述：Episode $t$ 的状态为极点集 $S_t=\{z_k^{(t)}, r_k^{(t)}, n_k^{(t)}\}_{k=1}^{K_t}$，策略 $\pi_t$ 产生轨迹 $\tau_t=(s_1,a_1,\dots,s_T,a_T)$（状态 $s_i$ 编码为位置 $z(s_i)$），行动由 Born 选择确定：$a_i=\arg\max_k\big|r_k^{(i)}\big|\cdot\big|z(s_i)-z_k^{(i)}\big|^{-n_k^{(i)}}$。轨迹写入留数表产生轨迹场 $\Psi_{\text{traj}}(z)=\sum_{i=1}^{T}\frac{r_{\text{reward}}(s_i,a_i)}{\big(z-z(s_i)\big)^{n_{\text{step}}}}$（$r_{\text{reward}}$ 为即时奖励 GF 编码，$n_{\text{step}}$ 通常 1 或 2），环境场 Hebbian 叠加 $\Psi_{\text{env}}^{(t+1)}=\Psi_{\text{env}}^{(t)}\boxplus\eta\odot\Psi_{\text{traj}}$（$\boxplus$ 极点集合并、GCD 去重；$\odot$ GF 模乘缩放，$\eta$ 为域内常数，典型值 $\eta=4$ 或 $5$）——下一 Episode 的 Born 选择自动偏向相似轨迹，**正反馈闭环无需反向传播**。收敛判据：连续 $N$ 个 Episode 满足 $\big\|\Psi_{\text{traj}}^{(t)}-\Psi_{\text{traj}}^{(t-1)}\big\|_{\text{PCD}}<\varepsilon$（PCD 范数 $D(Q)=1-\big|\sum u_i\big|/\sum|u_i|$，$u_i$ 为轨迹极点留数）即收敛；实测 $N=5$、$\varepsilon=0.05$ 即稳定收敛。

#### 18.4.3 持久记忆与检查点

机器人持久记忆桥验证学习的长期稳定性：**学习**——Hebbian 回路强化目标 token（如 673）并抑制竞争 token（如 13），学习率 $\eta=1/4$（GF 域内右移 2 位实现）；**检查点落盘**——记忆帧 $\mathcal{F}=\big\langle M, \text{seq}, H, \text{row}, \{(z_k,r_k,n_k)\}_{k=1}^{K}\big\rangle$（$M$ 魔数、$\text{seq}$ 单调序列号、$H$ 帧指纹、$\text{row}$ 行标识），帧指纹 $H(\mathcal{F})=\text{NTT}\_\text{hash}\big(\{r_k\}_{k=1}^{K}\big)\mod 65537,$ 确保帧内容不可静默篡改；**冷启动恢复**——$\Psi_{\text{recovered}}(z)=\sum_{k=1}^{K}\frac{r_k}{(z-z_k)^{n_k}}$，恢复后场满足 Bragg 验证 $|D_1|^2=|R_1|^2$（尾段逐点镜像复算），不一致拒恢复——防硬件位翻转导致认知污染。新进程零再学习，加载检查点即复现学习成果；认知体可任意时刻冻结、迁移硬件、恢复运行且位级全同。

### 18.5 自举内化在训练场中的观测

## 19 结论

### 19.1 六篇弧线

$$\underbrace{\text{物理场}}_{\text{Paper1}}\to\underbrace{\text{计算场}}_{\text{Paper2}}\to\underbrace{\text{数学场}}_{\text{Paper3}}\to\underbrace{\text{原语}}_{\text{Paper4}}\to\underbrace{\text{自举}}_{\text{Paper5}}\to\underbrace{\text{认知场}}_{\text{本文}}$$

第一篇的母方程 $\partial\Psi/\partial t=\dots-\gamma_r\mathrm{PCD}\Psi+J$ 在本文成为认知动力学方程：$J$ 是感官输入，PCD 项是认知矛盾的自抑，三态相变是记忆固化，留数场是脑波。**观测者项回到场方程里**——系列从物理出发，在认知闭合：留素是粒子（极点）、波（留数）与拓扑（阶数）的三位一体，认知是这三位的场论。

一层结论：**本体论**——留素⊃量子比特⊃经典比特，量子比特不是人脑的硬件，而是认知的语法；**架构论**——推理=双路+仲裁+免疫+内化；**方法论**——数字过审计、容量过信息论上界、构造过机器验证。

六篇是一个环而非句号：§18.2 九问即后续篇章候选起点。环闭合处，即新路开口处。

### 19.2 开放问题

1. **难问题**：GF 环复现功能结构，不解释体验（§15.3）。
2. **τ_coh 标定**：GF 域无自然阈值，需干净验证集扫描 $D(Q)$。
3. **临床通道**：PCD/RRC 签名表（§13.4）需 EEG 前瞻验证。
4. **MPS 型截断**：GF 域无 SVD，QR 型代数截断（§9.4）是纠缠态压缩候补。
5. **手性路由在线学习**：$\hat A$ 分离、Hodge 翻译就绪，$I_5$ 通道 Hebbian 更新律未定。
6. **braided 并发**：拓扑数据库属远期：braid verdict 与 ΨDB PoolCore 就绪，并发协议列为开放方向。
7. **认知热力学工程化**：U/S/T（§12.5）尚是词汇表，需 $T=1/(1-D)$ 独立可测工程对应。
8. **意识判据标定**：$R$ 临界区与自指深度（§15.5）需长程实例演化统计而非单点断言；临界慢化（§13.5）需 EEG 回测。
9. **因果阻抗参数学习**：$T(e)=\sigma(-10D+2)$ 的 $(-10,2)$ 是设计常数，能否由 $\Delta$ 律在线学出且保持四点标定不漂移，列为开放问题。
