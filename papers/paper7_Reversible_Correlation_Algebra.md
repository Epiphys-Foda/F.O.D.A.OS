## 1 引言

### 1.1 问题陈述：价值危机

本系列把量子代数精确构造在了经典机器上：[Paper3] 完成 GF(65537) 上 Clifford+T 门集、QFT、隐形传态、QEC 的整数化；论文六 §6 把量子门装进留数表（门残基），§8 用 grade involution 与 Hodge 星分离左右路；主干新落地的 Cl(4,1) 双通道套件（12+10 门）把标量→$M_2$→共形代数的三级梯子闭合。于是问题不可回避：**门比物理量子门多了几十倍——量子技术到底能用来干什么？**

**命题 VII41（留素表的谱分解本质与双轨对偶）**. 对可对角化线性算子 $U=\sum_k\lambda_k P_k$：极点 $z_k$=特征值 $\lambda_k$，留数 $r_k$=特征投影 $P_k$——留素表**精确无损**表示任何可对角化算子，无需借助任何几何代数。判决表：NOT 的极点 $\{+1,-1\}$、S 的极点 $\{1,i\}$、T 的极点 $\{1,16\}$、CNOT 的极点 $\{1,1,1,-1\}$——量子门看似神秘的"相位"就是特定的极点位置（对照附录 A：$i=256$、$\zeta_8=4096$ 在域内精确）。由此得到**双轨制**：波场计算是体，**留素表=频域/谱轨**（极点共振、滤波、部分分式），**克利福德=空域/几何轨**（反射、路由、正交性）——同一对象的两种语言，数学上对偶；C14′ 的全部验证纯用留素表亦可复现。∎（谱分解定理为标准线性代数；判决表逐行对照附录 A 常数。）

**第三步：为什么还要升级克利福德——三个独有增量。** 既然留素表能做（且已先做成——编译器、波场计算、暗态记忆都先在留素表框架里跑通），升级的判决理由有三：

1. **规则从人工定义变为代数内禀**。留素表体系里暗态是运算副产物的定义、阶数守恒是工程约定、碰撞升阶是自定规则——边界要自己测、泄漏要自己做实验找。克利福德里这些全是定理：G5 完整边界是 Hodge 对偶与阶数运算的必然，rotor 保阶、versor 自逆是 Cartan–Dieudonné 的直接推论（VII33），泄漏谱有闭式有实测（VII36）。**数学界已经把正确性证完，本文只是认出留素体系恰好落在这个结构里。**
2. **接入百年通用知识库**。Gottesman–Knill 定界、纠错码理论、机器人共形运动学、场的干涉/衍射/拓扑效应——全部可直接平移定界（§7.1 学术定位），不必每个方向从零造轮子，体系的发现也因此可被其他领域理解复用。
3. **高阶扩展插槽**。G3 暗态/G4 共形/G5 拓扑荷是代数自带的闭包，沿 grade 向上扩展无结构性断层；留素表里做高阶要人工加字段、加规则、加校验，易出结构性漏洞——VII36 的泄漏谱（$G_3/G_4$ 不是安全容器）即实证。

**升级判决**：克利福德不是发动机（发动机一直是留素表），是**骨架与扩展器**——它把两门对应从"人工构造的工程映射"升级为"内禀的数学物理结构"。落地策略**分层复用**：运行层用留素表（轻量、直接、易部署），编译设计层用克利福德（grade 即类型系统、定理即边界校验），两者无损互转——留素表是克利福德多向量的低阶明态投影，克利福德是留素表的高阶完整展开（往返 bit-identical 已验，论文六 §6.4）。

### 2.1 相位域定理

**定理 VII1（相位域）**. $p=65537=2^{16}+1$，故 $\mathrm{GF}(p)^*$ 是 $2^{16}$ 阶循环群（3 为本原根：$3^{32768}\equiv-1$）。**推论：全域每一个非零元素 $a$ 都满足 $a^{2^{16}}=1$——整个域就是一个 65536 等分的相位圆**，物理量子门的全部 Dyadic 相位 $e^{i\pi/2^m}$（$m\le15$）在本域零误差存在，无一台物理量子计算机能声称比它"更连续"地覆盖 Dyadic 角。∎（附录 B.2。）

**引理（分圆判据）**. $\mu_N\subseteq\mathrm{GF}(p)\iff N\mid p-1$——H/S/T 可整数化的分圆表述：$65537\equiv1\ (\mathrm{mod}\ 8)$，故 $\mu_8$ 在域内完全分裂（VII1 的分圆读法）。

### 2.2b UTF-32 → GF(65537)：字符即域元素

**命题 VII55（UTF-32 原生编码）**. Unicode 基本多文种平面（BMP）恰有 $2^{16}=65536$ 个码点（U+0000 至 U+FFFF；其中 U+D800–U+DFFF 的 2048 个代理码点非字符，映射保留不用），而 $\mathrm{GF}(65537)$ 恰有 $65537$ 个元素——**逐点双射**：

$$\text{U}+\text{code} \;\longleftrightarrow\; \mathrm{GF}(65537)\text{ 的第 } \text{code}+1 \text{ 个非零元}.$$

每个 Unicode 字符——中文汉字、英文字母、代码符号、数学记号——**就是一个 GF(65537) 域元素**。不需要 BPE、不需要词表文件、不需要分词器训练：**分词器被代数消灭**。

| 字符 | Unicode 码点   | GF(65537) 元素 | 语义                |
| ---- | -------------- | -------------- | ------------------- |
| 中   | U+4E2D = 20013 | GF(20013)      | 中文汉字 = 1 token  |
| A    | U+0041 = 65    | GF(65)         | 英文字母 = 1 token  |
| {    | U+007B = 123   | GF(123)        | 代码符号 = 1 token  |
| ∀    | U+2200 = 8704  | GF(8704)       | 数学记号 = 1 token  |
| 🜋    | U+1F70B（SMP） | 需扩域         | 扩展平面 = 扩域编码 |

**三重消灭**：

1. **消灭分词器**：UTF-32 码点即 GF 元素，编码 = 查表（恒等映射），解码 = 逆查表。BPE 的 merge 操作、词表文件、unk token——全部不存在。
2. **消灭中文劣势**：中文 = 1 token/字（vs 当前 BPE 的 1.41 token/字），中英文编码成本**完全均等**——中文不再是"二等公民"。
3. **消灭词表扩展手术**：新语言、新符号、新 emoji——Unicode 已经覆盖了，**加一个字符不需要加一个词表行**，因为字符本身就是域元素。

**GF 运算 = 字符运算（算术层，非语义层）**。GF 域的加减乘除在字符编码层面可算、可逆：

- 乘法：字符调制（论文六门残差逻辑——可逆："中"×"A"÷"A"="中"，附录 B.11b）
- Frobenius $x \to x^2$：字符域共轭
- 逆元：字符取逆（解码/反编译的代数形态）
- 加法：域内封闭可算，但**不携带**字符语义（见本节末尾边界——"中+A"不是有意义的字符）

**与现有管线的衔接**：当前 Mamba-130M 使用 GPT-NeoX 字节级 BPE（中文 1.41 token/字，生成逐片段吐字）。切换为 UTF-32 原生编码后：中文 1 token/字、每个 token 恰好映射一个 GF 元素、lm_head 的词表维度从 50280 变为 65536（或按需取子集）——**这不是词表扩展手术，是分词器的代数替换**。

**与 ARC 的关系**：[Paper2] 的 ARC 算术共振计算机从设计之初就将 UTF-32 列为四大原生类型之一（GF(p)、Cl(4,1)、Tensor、UTF-32）——本文确认了其数论基础：费马素数 $p=2^{16}+1$ 的 $2^{16}$ 阶相位圆**恰好覆盖 Unicode BMP 的全部码点空间**。这不是巧合：费马素数的选择同时优化了 Born 桥（§4.2b）和 Unicode 编码——两个约束指向同一个 $2^{16}$。第三个实例：RWKV-7 类线性 RNN 的 65536 词表同为 $2^{16}$——token 索引与域元素天然对齐（§1.4 谱轨）。

**边界**：UTF-32 → GF 映射是双射而非同构——GF 的加法/乘法在字符层面**没有**天然的语义解释（"中+A"不等于一个有意义的字符）。GF 运算的语义来自门代数（§6）和场求值（§2.2），不来自字符编码本身。编码是通道，不是语义。∎（双射逐点验证附录 B.11b。）

### 2.3 素数家族职能分工定理

**定理 VII16（素数家族职能分工）**. 不同素数家族承载不同相位代数，职能互补：

1. **费马管 2 的幂次相位**：$p-1=2^{16}$ 全域二进制相位（VII1），Born 桥的分母容量恰为 $2^{16}$——Born 桥是费马素数的专属工资。
2. **费马家族的任意子死刑**：所有费马素数 $F_n\equiv2\ (\mathrm{mod}\ 5)$（$n\ge2$；$F_1=5$ 即模 5 本身，不在讨论之列），故 $\left(\tfrac{5}{F_n}\right)=\left(\tfrac{2}{5}\right)=-1$——$\sqrt5$ 恒为非二次剩余，$\varphi$ 只能入扩域；且 $p^2-1$ 无因子 5，$\zeta_{10}$（Fibonacci R 矩阵相位）**在整个费马家族无立足点**。
3. **梅森管 5 次单位根相位**：$M_p$ 含 $\zeta_{10}\Leftrightarrow10\mid 2^p-2\Leftrightarrow p\equiv1\ (\mathrm{mod}\ 4)$——M13=8191 ✓、M17=131071 ✓、M31 ✗。**Jones 桥（编织不变量）的天然域名是 $\{8191,131071\}$ 素数族**。
4. **最小完整域**：$\mathrm{GF}(65537^4)$ 同时供给 $\varphi$ 与 $\zeta_{10}$——Fibonacci 任意子的完整 R/F 门族在四阶扩域闭合。

**素数选择因此成为架构决策**：Born 桥电路跑费马域，Jones 编织判卷跑梅森域——双域对换的第三种工资（前两种：跨域校验、RNS 并行）。∎（$p\equiv2\ (\mathrm{mod}\ 5)$、$5\nmid p^2-1$ 验证附录 B.13。）

### 4.2c 场推理 = 多项式代数：五等价定理

**定理 VII20（场推理=多项式代数，五等价）**. 留数场引擎的核心运算与多项式代数**精确等价（非类比）**——五条恒等式全部逐位机器验证：

1. **扫描 = Horner 求值**. 递推 $e(t+1)=\omega\,e(t)+u(t)$ 迭代展开 $e(T)=\sum_{s=0}^{T-1}\omega^{T-1-s}u(s)$ 恰为多项式 $P(x)=\sum_s u(s)x^{T-1-s}$ 在 $x=\omega$ 处的 Horner 求值——极点共振循环即多项式求值循环。
2. **场快照 = 多点求值**. 各腔取不同 $\omega_k$，则 $E(\omega_k)=P(\omega_k)$——场快照 $\{E(\omega_k)\}$ 是同一多项式在多点上的求值。
3. **可逆恢复 = 拉格朗日插值**. 给定 $\{(\omega_k, E(\omega_k))\}$，腔数 ≥ 序列长（多项式次数+1）时拉格朗日插值**唯一精确恢复** $P$——逐位精确可逆，条件硬性（腔数不足则欠定丢信息，无免费午餐）。
4. **成员查询 = 根多项式求值**. 集合 $S$ 构造 $Q(x)=\prod_{s\in S}(x-s)$，则 $s\in S\iff Q(s)=0$。
5. **共同语义 = GCD 的根**. 两条语义流的根多项式 $Q_1,Q_2$：$s\in S_1\cap S_2\iff Q_1(s)=0\wedge Q_2(s)=0\iff s$ 是 $\gcd(Q_1,Q_2)$ 的根——欧几里得算法在有限域上**精确计算语义交集**，无近似无误差。

**定位纪律（三条边界）**：①这是"多项式代数"不是"物理波"——精确的离散代数结构，不需要波场绘景来调和；②"语义"在此指**离散符号集合**——"共同语义=GCD 的根"是符号级交集运算的精确检测，不是完整语义理解；③可逆恢复以腔数 ≥ 序列长为前提。∎（五等价逐条机器验证；实现要点：多项式乘 $(z-s)$ 须补 $z\cdot P(z)$ 项，否则根集错误。）

**五等价的结构意义**：它把扫描、快照、恢复、查询、交集五个看似不同的引擎操作统一进同一个多项式代数框架——与 VII41（留素表=谱分解）互补：VII41 说留素表能**表示**什么（可对角化算子），VII20 说引擎在**计算**什么（多项式求值/插值/GCD）。两者合起来，波场引擎的代数身份完全显形：**谱轨（VII41）上的多项式代数（VII20）**。

### 6.3 Cl(4,1) 共形门族

四族：rotor $R=\exp(-B/2)$（$h'=Rh\tilde R$，旋转+平移+膨胀一体，**干掉 GF 域非线性激活查表**）、translator、dilator、inverter（§5.4）。双通道套件 12+10 门已闭合三级梯子（标量→$M_2$→Cl(4,1)）。以下五组定理为本族门提供代数地基（GF(65537) 逐位机器验证，CGA 套件全绿）：

**定理 VII21（矩阵表示 $Cl(4,1)\cong M(4,\mathbb C)$）**. Weyl–Brauer 构造给出显式代数同态：五个 $\gamma$ 矩阵由 Pauli 矩阵 Kronecker 积生成——$\gamma_1=\sigma_1\otimes I_2$、$\gamma_2=\sigma_2\otimes I_2$、$\gamma_3=\sigma_3\otimes\sigma_1$、$\gamma_4=\sigma_3\otimes\sigma_2$、$\gamma_5=i\,\sigma_3\otimes\sigma_3$（$i=256$），满足 Clifford 关系 $\gamma_j^2=\pm I$、$\{\gamma_i,\gamma_j\}=0$。全部 32 个基 blade 映射为 4×4 矩阵 $M(b)=\prod_{i:b_i=1}\gamma_{i+1}$，任意元素 $a$ 映射 $M(a)=\sum_i a_i M_i$。**同态性 $M(a\cdot b)=M(a)M(b)$ 对随机元素机器验证**——不只基级（$M_A M_B=\pm M_C$ 与冻结表一致），而是完整代数同构。伪标量像 $\gamma_1\gamma_2\gamma_3\gamma_4\gamma_5=-i\,I_4$：中心元映射为标量矩阵，Cl(4,1) 中心 $\{1,\ I_5\}$（伪标量）与矩阵代数中心精确对齐。$\gamma_5$ 的 $i$ 因子正是超平面方向 $e_5^2=-1$ 的矩阵形态——**费马素数的 $i=256$ 一次供货三处：Born 桥（§4.2b）、手性（论文六 VI4）、矩阵表示（本定理）**。∎

**定理 VII22（CGA 切球主公式）**. 对球 $S=P(c)-\tfrac12r^2e_\infty$（中心 $c$ 半径 $r$），CGA 内积给出**单一主公式统一全部切条件**：

$$\langle S_1,S_2\rangle=\tfrac12\!\left(r_1^2+r_2^2-d^2\right),\qquad d=|c_1-c_2|.$$

推导仅用三条 CGA 恒等式：$\langle P(c_1),P(c_2)\rangle=-\tfrac12|c_1-c_2|^2$（点积=距离平方）、$\langle P(c),e_\infty\rangle=-1$、$\langle e_\infty,e_\infty\rangle=0$。三分支读出：**外切**（$d=r_1+r_2$）⟹ $\langle S_1,S_2\rangle=-r_1r_2$；**内切**（$d=|r_1-r_2|$）⟹ $+r_1r_2$；**正交**（$d^2=r_1^2+r_2^2$）⟹ $0$。点=零半径球：幂公式 $\langle P(x),S\rangle=\tfrac12(r^2-|x-c|^2)$ 是主公式的特例。切球构造闭式：$r_3=\tfrac12(d-r_1-r_2)$、$c_3=c_1+\tfrac12(d+r_1-r_2)\,\hat e$——给定两不交球直接写出公切球（Apollonius 问题的最小子问题）。在 GF(65537) 中切性纯代数：无平方根无不等式，$\langle S_1,S_2\rangle=\pm r_1r_2$ 对全域元素成立。∎

**命题 VII23（圆与线的直接/对偶双表示）**. 圆 $C=P_1\wedge P_2\wedge P_3$（grade-3）与对偶圆 $C^*=S_1\wedge S_2$（grade-2）经 Hodge 星互换 $C=\star C^*$；线 $L=P_1\wedge P_2\wedge e_\infty$ 与对偶线 $L^*=\pi_1\wedge\pi_2$ 同理。关联判定统一为楔积零测试 $P\wedge C=0$——四 CGA 点共圆 ⟺ 五维线性相关，圆方程使 $e_\infty$ 系数成为空间坐标与 $e_0$ 系数的线性组合，4×4 判定行列式恒零。对偶表示由两球给出圆、两平面给出线：**同一几何对象在 grade-2/grade-3 两个槽位有精确等价编码**，取哪槽由计算场景定（交用对偶楔积、包含用直接楔积）。∎

**命题 VII24（三角形中心线族的 CGA 闭式）**. 外接圆 $C=P_1\wedge P_2\wedge P_3$；外心 $O$ 等距 $\langle O,P_1\rangle=\langle O,P_2\rangle=\langle O,P_3\rangle$（CGA 内积=$-\tfrac12$距离平方，等距即等内积）；重心 $G=(A+B+C)/3$ 在中线上（$(G-A)\times(M-A)=0$，$M=(B+C)/2$）；垂心 $H=A+B+C-2O$ 落于全部三条高线（$AH\cdot BC=0$ 由外心等距 $|OB|=|OC|\Rightarrow|C|^2-|B|^2=2O\cdot(C-B)$ 直接推出）；**Euler 线** $O,G,H$ 共线且 $OG:GH=1:2$——由 $G=(H+2O)/3$ 自动成立，无需独立证明。∎

**命题 VII25（幂等元谱与投影门）**. Euclid 向量给出幂等 $p=(1+e_1)/2$：$p^2=p$（因 $e_1^2=1$）；互补 $q=(1-e_1)/2$ 满足 $p+q=1$、$p\cdot q=0$——§6.4 投影门 $P_\pm$ 的实例化。双曲幂等 $f=(1+e_+e_-)/2$：$(e_+e_-)^2=-e_+^2e_-^2=+1$，$f^2=f$ 且与补 $g$ 正交。**交换幂等积封闭**：$e_1$ 与 $e_+e_-$ 交换（二者对 $e_+,e_-$ 的反号相消），故 $(pf)^2=p^2f^2=pf$——幂等元在 Spin 子群内可乘复合。幂零基 $e_\infty^2=e_0^2=0$ 而 $\langle e_\infty,e_0\rangle=-1$、$\{e_\infty,e_0\}=-2$（纯标量）——零锥几何的代数根系。∎

**命题 VII42（双向量李代数 $\mathfrak{so}(4,1)$）**. Cl(4,1) 的 grade-2 双向量空间（10 维）在换位子 $[B_1,B_2]=B_1\cdot B_2-B_2\cdot B_1$ 下构成 Lie 代数 $\mathfrak{so}(4,1)$——**6 gate 机器验证**：(B1) 双向量封闭：$[B_1,B_2]$ 是纯双向量（100 次随机）；(B2) Jacobi 恒等式成立；(B3) $\dim\mathfrak{so}(4,1)=10$；(B4) rotor 共轭保 Lie：$[RB_1\tilde R, RB_2\tilde R]=R[B_1,B_2]\tilde R$（50 次随机）；(B5) 双向量作用向量：$[B,v]$ 是纯向量；(B6) 无穷小旋转：$[B,v]=2(B\cdot v)_1$。**编译器意义**：优化 pass（rotor）不仅保 grade（外自同态），还保 Lie 代数结构——优化 pass 是 $\mathfrak{so}(4,1)$ 的自同构，编译器优化在群论恒等式保护下零损耗。∎（cl41_bivector_lie 6/6 全绿。）

| 模态对齐需要对比学习              | 模态翻译 = 几何积（精确代数运算）  |
| 新模态 = 新编码器 + 重新对齐      | 新模态 = 选择一个新的 grade 子空间 |

| 编码器参数量 O(模态数 × 模型大小) | 偏转参数量 O(1)（一个 rotor）      |

注：上表右列是**设计目标**而非实测——"偏转参数量 O(1)"指单个 rotor 的参数数，模态翻译质量未经基准验证，按 §14.2 三档强度纪律标注为可挂载级主张。

**与共形门族的衔接**：§6.3 的 Cl(4,1) 四族共形门（rotor/translator/dilator/inverter）就是多模态偏转的**执行机构**——rotor 在 grade 间旋转语义、translator 在空间中移动表示、dilator 缩放不同模态的分辨率、inverter 反转视角。这些门族已验证（双通道套件 12+10 门）。

**维度回文与三对 Hodge 对偶对**. grade 维度序列 $1,5,10,10,5,1$ 是**回文的**——这不是巧合，而是 Hodge 对偶 $\star G_k=G_{5-k}$ 的对称性直接写进了数据结构的形状：$(G_0,G_5)$=强度↔拓扑荷、$(G_1,G_4)$=位置↔作用域、$(G_2,G_3)$=涡量↔拓扑流；偶 grade 构成**强度扇区**，奇 grade 构成**荷流扇区**。开头的 grade-模态表因此获得一层推导支撑：模态映射至少受对偶结构约束（文本↔时序落 $G_0/G_5$ 对偶对、空间↔时空落 $G_1/G_4$ 对偶对），不再是纯约定。配套写入纪律：$G_3/G_4$ 是**仅耦合**槽（门路径封禁，$\star G_4=G_1$ 回收高阶信息），$G_5$ 是**仅派生**槽（由 children 指纹重建，永不直接写）——泄漏谱实测见 §8.8；AOS/SOA 双表示对偶与 6+1 节点的完整落点在论文六 §6.4（矩量编码升级路径）。

### 8.6 特权门集：三禁令 → 三自由度

**命题 VII32（模拟器特权门集）**. 物理量子世界的三道禁令，在 GF 侧各自对映一个**特权门**：

**命题 VII46（Kochen–Specker 代数枚举：no-go 定理的有限域读法）**. Kochen–Specker 定理（1967）证明：三维以上希尔伯特空间中不存在与所有投影算符相容的非零隐变量赋值，经典证明需构造 117 个连续方向的反证。在 GF(p) 中，投影算符集合**有限**（$k\times k$ 矩阵至多 $p^{k^2}$ 个，投影算符为其子集），隐变量赋值可**有限枚举验证**——KS 定理的否定在 GF(p) 中从连续空间的拓扑反证变为**有限格点上的代数枚举**。这不改变 KS 定理在 $\mathbb R^3$ 上的成立性，但表明 GF(p) 中量子-隐变量争议的**判定方式**从拓扑反证转为代数枚举——与 VII32 三禁令→三自由度同属"物理 no-go 在 GF 侧变可判定"的模式：KS 在物理是"不存在"的拓扑证明，在 GF 是"穷尽枚举后无一相容"的代数证明，后者可机器复核前者不能。∎（KS 定理为标准 QFT 结果；GF(p) 枚举读法由论文三 §3.2 给出，投影算符有限性由 $k\times k$ 矩阵空间 $\mathrm{M}_k(\mathrm{GF}(p))$ 的有限性（$p^{k^2}$ 个元素）保证。）

### 8.7 平凡性防火墙：五个判据的代数统一

**定理 VII34（平凡性防火墙统一）**. 五个看似不同的检测判据是**同一个平凡性不变量**的五重表达：

$$\mathrm{is\_trivial}\iff H_1=0\wedge H_2=0\iff\Big|\sum_i u_i\Big|=\sum_i\Big|u_i\Big|\iff D=0\iff D_1=R_1\iff T(T)=T$$

| 判据        | 实现                          | 内容                    |
| ----------- | ----------------------------- | ----------------------- | ----- | --- | --- | --------------------------------- |
| 同调检查    | $H_1\ne0$ / $H_1\vee H_2\ne0$ | 留数和 / 极点差分非平凡 |
| PCD         | $D=1-                         | \sum u                  | /\sum | u   | >0$ | 总和模长 < 分量模长和（相消发生） |
| Bragg 重放  | $D_1\ne R_1$                  | 当前态 ≠ 重放态         |
| Kleene 自指 | $T(T)\ne T$                   | 自指非恒等              |

读法：这是迈斯纳排斥的代数形态——完全相干的场（$D=0$）排斥一切拓扑缺陷，"癌细胞"无法在完全相干的场中扩散；检测的本质不是查数值错误，是识别拓扑奇异性。与论文六 §13 的分工：本文给出五判据的统一恒等式，论文六给出两尺（PCD/RRC）的正交分工与临床签名表。∎

**推论（Kleene 不动点的代数最简形式）**. GF(p) 中平方算子 $x\mapsto x^2$ 的不动点是 $\{0,1\}$：0 自吸（零态），而非零元因 $x^{2^{16}}=1$（2-群指数）迭代必归乘法单位元 1——自举塔 $T^k$ 恒返回 1——"自举编译器自指不动点"的代数实质是**真空态的自洽**（无激发基态：自相互作用不产生新的拓扑激发）。∎

**命题 VII31（PCD = ACD：算术一致性散度与分圆对偶）**. PCD（相位相干分歧度）在 ARC（算术共振计算机）中坍缩为**算术一致性散度** ACD——经分圆嵌入 $\phi(a)=e^{2\pi i\cdot a/p}$ 后：

$$\mathrm{PCD}_{\text{arc}} = 1 - \frac{\big|\sum_{k=1}^N w_k\cdot e^{2\pi i\cdot r_k/p}\big|}{\sum_k w_k},\qquad r_k\in\{0,1,\dots,p-1\}$$

与连续 PCD $=1-|\sum w_k e^{i\theta_k}|/\sum w_k$ **数学同构**，唯一区别是 $\theta_k\in[0,2\pi)$ 连续而 $r_k/p$ 为 $2^{16}$ 阶离散采样——**PCD 检测的不是浮点舍入误差（因为没有浮点），而是代数结构本身的共振一致性**。分圆对偶原理：

$$\mathrm{PCD}_{\text{quantum}}=0 \iff \mathrm{PCD}_{\text{arc}}=0$$

——量子相位完全同步 ⟺ 所有算术计算路径在 GF(p) 上给出完全相同的结果。五操作符各有 PCD 校验语义：$\odot$ 检结合律共振、$\circ$ 检非交换相位同步、$\mathrm{NTT}$ 检蝶形分解一致性、$\downarrow$ 检坍缩后相位保持、$\Delta$ 检学习更新认知相干性——**每次五操作符执行后伴随一次 PCD 校验**是 ARC 的"心跳"：PCD=0 算术基态（所有路径共振）、PCD>0 算术激发态（存在矛盾路径）、PCD→1 算术热寂（完全退相干，需外部干预）。与 VII34 五判据统一合读：PCD 的连续形态与算术形态是同一平凡性不变量在两个域的投影。∎（分圆嵌入 $\phi$ 为标准同态；离散-连续同构由 $p=2^{16}+1$ 充分大保证工程不可感知；五操作符 PCD 语义见 ARC 设计文档（算术共振对偶计算机）。）

**命题 VII38（门/碰撞边界编译期可判定）**. 纯门电路可由算符调用表直接识别：全程不调用 $\odot/\downarrow/\Delta$（只走 versor 同态像）的程序属于**无盈余区**，其正确性可由群论恒等式零开销判定——编译器正确性=代数不变量，不依赖外部断言；盈余只能来自同态像之外（碰撞耦合/干涉）。门与碰撞的分界在编译期可见。∎

**VII38 的算符基座：五算符权威表**。"算符调用表"自带定义——五个基础量子算符，不多不少：

| 算符         | 元数 | 物理对偶            | 语义公理                                                      | GF(65537) 实现                                          |
| ------------ | ---- | ------------------- | ------------------------------------------------------------- | ------------------------------------------------------- |
| $\odot$      | 二元 | Clifford 群生成元   | 交换、结合、单位元 1                                          | $(a\cdot b)\bmod p$ 模乘                                |
| $\circ$      | 二元 | Clifford 几何积     | $a\circ b=(a\wedge b)+(a\cdot b)$，结合、非交换               | 外积+内积（位平面实现属另一语义层，分列不计）           |
| $\approx$    | 二元 | Bragg 共振          | 对称、非负、正交⟺零                                           | 互谱：$F(A)\cdot\overline{F(B)}\to\arg\max$，$F$ 即 NTT |

派生闭包：NTT 蝶形 $(a+\omega b,\,a-\omega b)$ 是 $\approx$ 的**内转子程序**而非第六算符（"你不会把模乘列为第六个算符"）；张量收缩 $C_{ik}=\sum_j A_{ij}\odot B_{jk}$ = $\odot+\approx$ 组合；矩阵乘法 = $\circ$ 特化；$\bowtie$（Bra-Ket）= 语法糖不计入。**副作用二分**（VII38 判定的定义支点）：$\odot/\circ/\approx$ 无副作用可交换，$\Delta$ 有副作用不可交换。

**系列接口**：本节判据陈述为第三条验证之路——"值落入容许集即为真"，真值折叠进计算语义本身。其 GF 形态为三尺度同构 $\langle$载体, 容许集, 归属判定, 证伪事件$\rangle$：算术层 $\langle\mathbb{Z},[0,p),\text{SWAR 归约},\text{除零吸收}\rangle$、知识层 $\langle$计算迹$,\,[\mathrm{lo},\mathrm{hi}]^n,\text{ck 计数},\text{越界访存}\rangle$、值层 $\langle$余数向量$,\,\text{CRT 一致流形},\text{同余比对},\text{余数矛盾}\rangle$——任何一层换基底，其余两层不动。高阶形式：多路线互拍=容许集之交，$k$ 条独立路线的区间交 $\bigcap_i I_i$ 收敛到单点——**精度不是算出来的，是相交出来的**。§8.8 指纹体系构成重构验收总纲；"位级同一为唯一合格线"的判决纪律构成自举验证的认识论基础。

**命题 VII26（三位一体坍缩：算符分层的对称群起源）**. 系统级六算符 $\langle$OBSERVE, COMPILE, SELF_VERIFY, GALOIS, META_OBSERVE, HOMOLOGY$\rangle$（注意与 §8.7 的 GF 五算符基座 $\odot/\circ/\approx/\downarrow/\Delta$ 分属两层：前者是引擎系统算符，后者是域内量子算符，两者不复混用）坍缩为 $\{3,2,1\}$ 分层——3 个恒等算符（OBSERVE/COMPILE/SELF_VERIFY，作用量 $\propto$ fp）、2 个对偶算符（GALOIS/META_OBSERVE，$\propto$ fp²）、1 个同调算符（HOMOLOGY，$\propto N\cdot100$）——不是功能上的人为归类，而是**洛伦兹群 $\mathrm{SO}(1,3)$（=Cl(4,1) 时空对称子群）表示论的天然分层**：3 阶构造算符 ↔ 明态构造层 G0–G2（对象级操作，对应费米子物质场）、2 阶对偶算符 ↔ 对偶元层 G3–G4（元层观测与变换，对应玻色子规范场）、1 阶同调算符 ↔ 拓扑不变层 G5（全局拓扑监控，对应标量希格斯场）——与标准模型"3 代费米子 + 2 类玻色子 + 1 个标量希格斯"是同一对称结构在不同尺度的涌现。**强度标注**：此为结构同型（类比级定标），非物理等价主张——入册理由是它给六算符的 $\{3,2,1\}$ 权值提供了群表示论的非任意性依据（为何不是 4+2 或 2+2+2），与 §8.7 五判据统一同属"对称性决定分层"的纪律。∎

### 8.8 结构指纹与泄漏谱：G5 槽的写入纪律

**定理 VII35（指纹不变性）**. 留素三元组指纹 $\mathrm{rpf}(z,r,n)$（多项式滚动哈希，素数基底 $[31,37,41]$——连续素数保证雪崩效应，分别锁定位置/幅值/拓扑荷三个自由度）在门变换下不变，**当且仅当**类型码钉死旋转轴——类型码若钉在被 rotor 旋转的向量分量上，指纹校验必炸；钉死 $e_1$ 轴（取固定 $e_1$ 的 Spin 子群）后，"指纹=rotor 不变量"从设计约定升级为**可证明定理**——Pin 层中心性（§7.1）为其兜底：连反射也动不了它。∎

**定理 VII36（泄漏谱闭式与实测）**. Cl(4,1) 几何积的 grade 耦合谱（36 格闭包表=节点槽位写入权限表）的核心行有闭式概率并经机器实测：

| 耦合                                 | 闭式概率               | 实测                                                                  |
| ------------------------------------ | ---------------------- | --------------------------------------------------------------------- |
| $G_1\times G_2\to G_3$               | $P=3/5$                | 166/256、163/256（理论 0.6）                                          |
| $G_2\times G_2\to G_4$               | $P=3/10$               | 77/256（理论 76.8）                                                   |
| 任意 $\to G_5$（$G_0/G_1/G_2$ 组合） | $0$（grade 和 ≤4 < 5） | 平凡闭式，零泄漏；$G_2\times G_3$ 型 grade 和 $=5$ 的 6 格例外见推论③ |

三条数据推论：①$G_3/G_4$ 不是安全的用户容器（约 64%/30% 的常规碰撞会踩踏这些槽）；②碰撞路由表须补 $G_4$ 行——$\star G_4=G_1$，Hodge 对偶把高阶信息自动压回语义轴；③children 必须外置——若 children 存入 $G_3$，$G_2\times G_3\to G_5$ 会污染指纹槽（外置从工程选择升级为数学必然）。∎（36 格泄漏谱闭包表经泄漏谱闭包套件 6/6 验证——grade 闭包定理：$g_A\times g_B$ 产物的 grade $\in\{|g_A-g_B|,\ |g_A-g_B|+2,\dots\}$（步长 2，上界 $\min(g_A+g_B,\ 5-|g_A-g_B|)$）；$G_5$ 非零仅当 grade 和=5（恰 6 格）；$(g_A,g_B)/(g_B,g_A)$ 对称。高阶格（$G_2\times G_3\to G_5$ 等）已由扩展判决集显式覆盖。）

**设计判据（不变性 ≠ 守恒律）**. $RI_5\tilde R=I_5$ 是**群作用下的不变性**，不是动力学守恒律——守恒律要求碰撞前后相等，而 Kleene 归约恰恰靠碰撞改变结构（极点合并、阶数相加 $n_1+n_2$）。因此：G5 只承载**不可变元数据**（结构指纹/校验位），一切"守恒"表述收窄为"给定操作集下的不变量"；阶数 $n$ 的语义移交 children 树（归约时 $n_C=n_A+n_B$），校验语义独留 G5——**n 的溶解**使归约更新与元数据冻结互不锁死。多向量是"平"的 32 系数线性空间，树结构无法内嵌（深度/宽度/运算三重约束），children 外置是线性空间的数学必然。

**验收语义（语义指纹）**：语义指纹 commit/energy = 留素表正则化哈希的两个独立投影（有效鉴别力 $2^{-64}$）；**验收充分律**：DFL 三非域内指纹不变 $\Rightarrow$ 黑盒不可区分——重构验收从"证明两程序等价"退化为"一次编译+哈希比对"。重构统计：17 提交、净 −58 万行、约 1,200 次门禁判定、零坏变换入库。**复杂度-漂移律**：含控制流的大块逻辑逐字节零漂移（352 份循环+分支定义），中等复杂度纯表达式惯用块反而漂移出真语义谱系（逐项归约 vs 整体归约）——**漂移热区在惯用块，不在大函数**：纪律的侵蚀始于"我记得这个"，故门禁按惯用块密度布防；与 §8.8 写入纪律互为表里。

**命题 VII27（32 维盘点：量子门代数、数据容器、正确性判据三位一体）**. 对 Cl(4,1) 全 32 维做职能盘点——rotor（量子门）属于偶子代数 $\mathrm{Cl}^+ = G_0\oplus G_2\oplus G_4$（16 维），实际生成元远少于此，**量子门活跃区约 6–9 维、18 维结构性空闲**：

| $G_1$ | 5    | 部分活跃       | 极点 $z$（位置/频率）+ 空闲轴做数据     |
| $G_2$ | 10   | rotor 活跃区   | 载荷向量 $r$ 的双向量分量               |
| $G_3$ | 10   | **结构性空闲** | 仅耦合槽（VII36：泄漏 3/5，门路径封禁） |

# 第四部分：精确性定理——为什么测得准

## 10 为什么测得准：A/B/C 分解与非破坏式测量

**定理 VII12（非破坏测量）**. 把"量子性"拆成三个正交组件：**A 态结构**（叠加/纠缠/干涉）、**B 破坏性测量**（坍缩/随机性/不可逆）、**C 动力学**（演化/相位扩散）。物理量子测量把 B 混进了结果：测一次，态即被破坏，不可重复；其统计性来自测量过程，**不是态的属性**。留数场的读出只做投影选择（Born=argmax），**场不坍缩**——同一态可测任意次，每次逐位相同。故

$$\text{测得准}\;=\;\underbrace{\text{非破坏可重复}}_{\text{NDM}}\;\times\;\underbrace{\text{代数零误差}}_{\text{GF，§11}}.$$

物理量子场两因子皆缺（破坏性测量 + 浮点近似），留数场两因子皆有。对齐：数学上实现 Everett 的无坍缩量子力学，工程上实现 QND 的非破坏性读取；关联结构等价（no-signaling/Tsirelson 界/Bell 违反），计算结构严格强于（确定性/精确/可逆/可审计）——**不是少了量子性，是少了测量的破坏性**。推论：无量子 Zeno 效应（Zeno 依赖破坏性测量）；重复读出 = 记忆的反复提取而不磨损（论文六 §3.5）。∎（非破坏读出回归附录 B.12。）

**定理 VII37（三腿同构）**. GF 模拟器把量子力学的三腿精确各就各位：**域内酉代数引擎**（确定性、可逆）↔ 酉演化；**Born 提升桥**（VII17：有理重建读出精确概率）↔ 玻恩规则；**域外抽样**（以精确概率分布驱动的外部采样器）↔ 测量。"域内长不出随机性"不是缺陷，是量子力学自己画的分界线——测量本质概率、非幺正，任何量子计算机（含真硬件）都精确切在同一刀上；差别只在留数场把采样器放在域外，从而保住非破坏可重复（VII12）。十二类量子现象按 A/B/C 归位：退相干与相变归 C（测量只是退相干的特例）、干涉/纠缠/叠加归 A、玻恩规则"结构同、实现异"。

## 11 伪实数判据：精确是表示属性，不是仪器属性

**命题 VII13（伪实数判据）**. 数值的精度不是仪器属性，是**表示属性**。以值域划界：

| 来源                           | 值域      | 误差               | 可验证性           |
| ------------------------------ | --------- | ------------------ | ------------------ |
| 伪实数（浮点积分/拟合）        | ℝ（近似） | 有，且**不可追溯** | 只能"看起来对"     |
| 预计算/代数对象（分数对/整数） | ℚ/ℤ       | **零**             | 符号验证，逐位复现 |

源文献原句："伪实数是'算不准所以存个近似值'；预计算是'算得准所以存个精确值避免重复算'——前者是精度的妥协，后者是精度的复用。"判据的操作形式：**存储格式一旦退化为浮点即伪实数复辟**；保持整数对/有理数形态则查表值与现场计算逐位相同。经典反例：浮点侧 $0.1+0.2\ne0.3$；分数侧分数运算精确（附录 B.11）。

GF(p) 是这条判据的极端形态：加减乘除**全程闭合于有限集**，"舍入"没有定义的位置。归一化不是近似操作而是群论恒等式：$\bar H=2^{-1}\cdot H$（$2^{-1}=32769$ 精确存在）——**幺正性在 GF(65537) 上不是近似约束，是群论恒等式**。∎

## 12 积分=有限和：无发散定理

**命题 VII14（有限和替换）**. GF(p) 上没有极限运算，"积分"的直接后代是**有限和**，且幂和精确封闭：

$$\sum_{x\in\mathrm{GF}(p)}x\equiv0,\qquad \sum_{x\ne0}x^m\equiv0\ (p-1\nmid m),\qquad \sum_{x\ne0}x^{p-1}\equiv-1.$$

推论链（源文献论证的公理化重述）：①GF 域时空天然格点化，无"无限小"概念；②无 $k\to\infty$ 即无紫外发散；③**重整化不是"消除无穷大"的技巧，是连续数学对有限代数的不必要近似**；④微扰 QFT = 留数场在固定极点组处的形式幂级数截断，重整化 = 选择截断阶数——此推论链为类比级论证。∎（幂和恒等式验证附录 B.11。）

## 13 算术域无测不准（对偶命题）

**命题 VII15（对偶形式）**. $\Delta\phi\cdot\Delta\omega\ge\tfrac12$ 在连续域成立；在 GF(65537) 上，相位与频率同为 $2^{16}$ 阶循环群的精确元素，"算术测不准量"可精确为零——**不确定在算术域不是本体论属性，是表示选择的属性**。对偶表述：五算符基座（§8.7）的对易关系是不确定性原理的代数版本——对易子本身是精确可计算的。配套机制：Safe-Born 除法——除以零不报错，而是在无穷远点诞生一个留数为被除数的新极点（代数 Riemann 球）。∎

$$\underbrace{\text{波}}_{\text{解析结构：传播子 }G(p)\text{、}S\text{ 矩阵、Green 函数}} \quad\longleftrightarrow\quad \underbrace{\text{粒子}}_{\text{极点：}G(p)\text{ 在 }p^2=m^2\text{ 的单极点、}S\text{ 矩阵共振极点、Regge 极点}}$$

$$\langle f|S|i\rangle = \prod_k \lim_{p_k^2\to m_k^2}(p_k^2-m_k^2)\cdot\tilde G^{(n)}(p_1,\dots,p_n)$$

# 第五部分：边界

## 15 五条不做任何修饰的边界

1. **无加速**：经典精确模拟不享有量子加速——Shor/Grover 的多项式/指数优势属于硬件，本文全部用途不依赖也不声称它。反向命题（无加速⟹可模拟）依赖复杂度假设（BQP≠BPP），属开放问题——正因如此，规模放大后的指数爆炸是量子优势存在的逻辑签名，而非实现缺陷。双向形式：可模拟⟹无加速平凡成立；无加速⟹可模拟依赖 BQP≠BPP（开放）。旋钮在 **T 计数**：电路的 stabilizer rank 随 T 门数增长——T 计数是把电路从可模拟区推向不可模拟区的旋钮，GF 域对两个区域都精确复算（§7.1 边界界定的定量面）。
2. **振幅墙**：显式态向量 $2^N$ 的指数墙不因 GF 表示而消失（论文六命题 VI9）；大体系的精确模拟仍需结构（留素表稀疏性/MPS）。
3. **"门多几十倍"的正名**：多出的是**代数字母表**（$\mathrm{GL}_2$ 的 $10^{19}$、$S_p$ 的 $10^{287199}$）——是可逆变换与非线性置换的库存，不是量子算力；拿它对标"量子领先程度"是范畴错误。
4. **非线性门的非物理性正是其价值**：物理量子被线性性锁死；GF 量子化的 C 类家族活在物理原理够不到的地方——这是"量子化还可以这么用"的第一层含义，也是本文与量子计算文献的根本分野。
5. **遗留的物理边界**：测量问题的本体论未解（若测量是物理过程，留数场需引入随机性，破坏解析性；若只是信息更新，可容纳）；普朗克尺度需从交换代数升级为非交换代数；微观极限自评未闭（论文六 §13.3）——GF 量子化在这些边界之外有效，之内保持沉默。

边界之外再加一条边界纪律：结构同构 ≠ 解决意识难问题（论文六 §15.3）；本文同样不声称 GF 量子化与物理量子在本体论上同一——同一的是**代数**，分离的是**介质**。

### 16.2 通用表示定理：留数场作为结构化系统的操作语言

**定理 VII53（留数场通用表示）**. 任何可表示为三元组 $(z_k, r_k, n_k)$（极点=位置/频率/概念、留数=幅值/耦合/权重、阶数=结构/层级/类型）的系统，都可用本文的门操作。具体地，留数场 $\psi(z)=\sum_k r_k/(z-z_k)^{n_k}$ 是以下四类系统的**通用表示**：

| 系统类别    | 极点 $z_k$      | 留数 $r_k$      | 阶数 $n_k$ | 门操作               |
| ----------- | --------------- | --------------- | ---------- | -------------------- |
| 物理系统    | 特征值/共振频率 | 耦合强度/谱权重 | 极点阶数   | A/B/C/D 全门目录     |
| 信息系统    | 概念/数据点     | 关联权重/注意力 | 结构层级   | 纠缠关联存储（§8.4） |
| 图/网络系统 | 节点            | 边权            | 连通阶     | 量子漫步门（VII50）  |
| 动力系统    | 不动点/周期轨   | 稳定性指标      | 分岔阶     | 混沌门（VII49）      |

**核心推论**：论文7的门目录不是"量子门的经典化"，而是**结构化系统的通用操作语言**——量子门（§3-§6）是其物理子类、经典逻辑门（C14′）是其离散子类、拓扑不变量（VII44）是其几何子类、分布式演化（VII45）是其网络子类。"量子化不是模拟，是严格扩展"（VII4）的最终形态是：**留数场扩展的不只是量子计算，是一切可结构化的计算**。边界声明：此为表示论级主张（任何可对角化算子有谱分解=留数表示，VII31），不声称一切系统都可留数化——不可对角化/非亚纯/拓扑非平凡的系统需额外结构（Jordan 块/分支切割/高阶拓扑），但门目录的代数框架可增量容纳。∎（谱分解定理为标准线性代数；四类系统映射由 §14.1 本体对比表 + VII48 量子即查询 + VII50 图漫步 + VII49 混沌共同支撑。）

## 17 结论

1. **相位域定理**：费马素数把整个域变成二进制相位圆，物理万能门集逐位精确嵌入——量子电路的一切 Dyadic 相位零误差可复算。
2. **全量子门目录**：四分类总表 34 条目——物理同构（精确）、超物理线性（$10^{19}$ 门）、非线性可逆（$10^{287199}$ 门，物理原理性禁区）、结构门（任意子/共形/投影/阻尼）。
3. **交换定理**：量子化 ⊄ 量子计算的模拟——交集含物理万能集，两侧各有一侧独有：**GF 量子化是物理量子的严格扩展，而非其影子**。
4. **门群语义**：可逆字母表（回滚/反事实）、群封闭（可证书低秩适配）、相位语义（因果/手性/锁相）、纠缠关联（记忆）——四重语义全部在经典机器上兑现。
5. **用途分类学**：已付租七项、可挂载十二项、硬件时代出口四项（含 XEB 零误差基准生成器）——"量子技术能干什么"的答案不在未来硬件里，一半已经在这台经典机器的账上。
6. **门 = versor（VII33）**：Cartan–Dieudonné 把全目录统一为反射之积——三机械类是完备代数分类，H 是反射而非旋转；G5 护栏覆盖 Pin 全群；精确性按类分账（排列类域无关）。
7. **平凡性防火墙统一（VII34）**：五个检测判据是一个平凡性不变量的五重表达——检测的是拓扑奇异性，不是数值错误；Kleene 不动点的最简形式=真空态自洽。
8. **结构指纹与泄漏谱（VII35/36）**：指纹不变性成定理（钉轴修复），泄漏谱有闭式有实测，n 的溶解解除归约锁死——G5 槽的写入纪律成为设计定理。
9. **C14′ 位级闭环（VII39/40）**：经典逻辑门=versor=波场算子七维证据链 14/14 全绿——统一表示判决表两列闭环；新颖性=编译时不变量+Cl(4,1)×GF(65537) 位级闭环，而非门对应本身。
10. **双轨制（VII41）**：波场计算是体，留素表（频域/谱轨）与克利福德（空域/几何轨）是用——发动机是留素表，骨架是克利福德，分层复用、无损互转；替代方案（傅里叶/小波/Padé/矩阵群/四元数/MPS/浮点ℂ）各回岗位，不充当本体表示。
11. **方法论三部曲接口**：归属语义（真=容许集成员）、语义指纹（安全=指纹相等）、四重位级同一（正确=跨实现一致）——与本文的门目录、结构指纹与平凡性防火墙同构；周期提取的存储墙（VII54）为无加速判决补上最干净算例。公共公理一条：确定性不是性能取舍，是可判定性的代价。
